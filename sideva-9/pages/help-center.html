Tentang SI-DEVA9
SI-DEVA9 merupakan aplikasi pendukung proses pengadaan barang/jasa pemerintah untuk membantu OPD menyusun kebutuhan, melakukan survei harga, menghitung HPS, menyusun dokumen administrasi, dan mempersiapkan pengadaan sebelum dilaksanakan melalui sistem resmi pengadaan pemerintah.
Hak Akses Pengguna
  • SUPER_ADMIN → Mengelola seluruh sistem SI-DEVA9.
  • ADMIN_OPD → Mengelola data OPD masing-masing.
  • PPTK → Menyusun kebutuhan dan paket.
  • PPK → Verifikasi dan persiapan pengadaan.
  • PBJ → Melaksanakan proses pengadaan.
  • VIEWER → Monitoring dan pelaporan.

Panduan Teknis SI-DEVA9
Import RUP dari SIRUP
  1. Buka portal SIRUP LKPP.
  2. Cari paket RUP yang akan diimpor.
  3. Tekan F12 pada browser.
  4. Buka tab Network.
  5. Refresh halaman RUP.
  6. Cari request yang berisi data RUP.
  7. Klik request tersebut.
  8. Buka tab Response.
  9. Klik kanan → Copy Response.
  10. Buka menu Import RUP SI-DEVA9.
  11. Paste ke kolom Import JSON SIRUP.
  12. Klik Import Data JSON.
Jangan menyalin data dari tab Preview. Gunakan tab Response agar format JSON tetap valid.
Status Paket
  • DRAFT → Paket masih dalam penyusunan.
  • HPS_COMPLETE → HPS selesai dihitung.
  • BAHPE_COMPLETE → Dokumen BAHPE selesai.
  • READY_PROCUREMENT → Siap diserahkan ke PBJ/SPSE.
