Pusat Bantuan SI-DEVA9

Panduan penggunaan Sistem Informasi Digital Evaluasi Verifikasi Administrasi E-Purchasing.

Tentang SI-DEVA9
SI-DEVA9 merupakan aplikasi pendukung proses pengadaan barang/jasa pemerintah untuk membantu OPD menyusun kebutuhan, melakukan survei harga, menghitung HPS, menyusun dokumen administrasi, dan mempersiapkan pengadaan sebelum dilaksanakan melalui sistem resmi pengadaan pemerintah.
Hak Akses Pengguna
  • SUPER ADMIN → Mengelola seluruh sistem SI-DEVA9.
  • ADMIN OPD → Mengelola data pengadaan pada OPD masing-masing.
  • PPTK → Menyusun kebutuhan dan data paket.
  • PPK → Verifikasi dan persiapan pengadaan.
  • PBJ → Melaksanakan proses pengadaan.
  • VIEWER → Monitoring dan pelaporan.
Lihat Matriks Hak Akses
Alur Kerja SI-DEVA9
  1. Import / Input RUP
  2. Membuat Paket Pengadaan
  3. Mengisi Rincian Barang/Jasa
  4. Melakukan Survei Harga
  5. Menghitung HPS
  6. Menyusun Dokumen Persiapan Pengadaan
  7. Menyusun BAHPE
  8. Ready Procurement
  9. Diserahkan ke PBJ/SPSE
Status Paket
  • DRAFT → Paket masih dalam proses penyusunan.
  • HPS_COMPLETE → HPS telah selesai dihitung.
  • BAHPE_COMPLETE → Dokumen BAHPE selesai.
  • READY_PROCUREMENT → Paket siap diproses pengadaan.
Pertanyaan Umum (FAQ)

Siapa yang dapat menambah user?
SUPER ADMIN.

Siapa yang dapat mengubah OPD?
SUPER ADMIN.

Mengapa menu saya berbeda?
Karena setiap role memiliki hak akses berbeda.

Mengapa tidak bisa membuka halaman tertentu?
Karena halaman tersebut tidak termasuk hak akses role Anda.
