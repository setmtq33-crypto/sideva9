Dashboard

pages/dashboard.html

Pusat komando untuk monitoring seluruh paket. Desain sama persis seperti yang Anda lihat saat login.

5 KPI Utama
  • Total Paket
  • Total Nilai Pagu
  • Paket Siap Procurement
  • Dalam Proses
  • Paket Selesai
2 Grafik Interaktif
  • Tren nilai paket per bulan
  • Distribusi status paket
Tabel Status 9 Tahap

Memetakan bottleneck: dari DRAFT sampai PROCUREMENT. Klik angka untuk filter tabel bawah.

Rekap OPD & Monitoring Paket

Super Admin melihat semua OPD. Admin OPD hanya melihat OPD-nya. Ada quick search, filter status, dan export.

Pratinjau: KPI Cards + 2 Grafik + Tabel 9 Tahap
Paket packages.html

Kelola master paket pengadaan. Ini adalah pintu masuk semua proses.

Field utama: package_name, budget_ceiling, package_status, opd_id, fiscal_year, package_type

  • Tambah paket manual atau dari Import RUP
  • Edit hanya bisa saat status DRAFT / INPUT_ITEM
  • Hapus = soft delete, tercatat di Audit Logs
Pastikan nama paket sama dengan RUP SIRUP agar sinkronisasi lancar.
Items package-items.html

Input rincian barang/jasa untuk setiap paket.

  • Nama item, spesifikasi teknis, qty, satuan, sumber anggaran
  • Bisa import dari Excel template
  • Total items otomatis menjumlah ke pagu paket
Survei Harga price-surveys.html

Kumpulkan harga pasar sebagai dasar HPS yang akuntabel.

  • Minimal 2-3 vendor per item
  • Simpan bukti: link e-commerce, quotation PDF, screenshot
  • Sistem rekomendasikan harga wajar (median/terendah)
Dokumen package-documents.html

Upload dan kelola dokumen pendukung.

Wajib: KAK, DPP/Spesifikasi, RAB, Justifikasi

Disimpan di Supabase Storage dengan versioning otomatis. Preview PDF langsung di browser.

HPS hps.html

Hitung Harga Perkiraan Sendiri otomatis dari Items + Survei.

  • Klik "Generate HPS" → sistem tarik harga survei terbaik
  • Tambah overhead, pajak, profit sesuai aturan
  • Export PDF HPS yang sudah ditandatangani digital
  • Setelah APPROVAL, HPS dikunci (locked)
Ready Procurement procurement-ready.html

Filter otomatis semua paket dengan status READY_PROCUREMENT. Halaman ini adalah checklist terakhir sebelum kirim ke Pokja/LPSE. Pastikan dokumen lengkap, HPS locked, dan pagu sesuai.

Audit Logs audit-logs.html

Jejak digital lengkap: siapa mengubah apa dan kapan.

Mencatat: user_id, action (CREATE/UPDATE/DELETE), table, old_value → new_value, timestamp. Tidak bisa dihapus. Gunakan filter tanggal dan paket.

Users users.html

Manajemen pengguna berbasis role.

  • super_admin: semua OPD
  • admin_opd: kelola 1 OPD
  • ppk: approve paket
  • viewer: read-only
OPD opds.html

Master data Organisasi Perangkat Daerah. Dipakai di semua dropdown paket, dashboard, dan filter. Hanya Super Admin yang bisa tambah/edit.

Import RUP rup-import.html

Upload Excel hasil ekspor SIRUP LKPP.

  • Sistem mapping otomatis: kode RUP, nama paket, pagu, sumber dana
  • Validasi duplikasi berdasarkan kode RUP + tahun
  • Setelah import, lanjutkan lengkapi Items & Survei

Autentikasi auth.js

Login menggunakan Supabase Auth.

  • Email + password, session disimpan 8 jam
  • Auto-refresh token, logout otomatis saat expired
  • Role dibaca dari tabel users, bukan dari JWT saja
Super Admin

Fitur khusus untuk administrator sistem.

Selector OPD di topbar menyimpan pilihan ke localStorage['selected-opd-id']. Semua halaman (Dashboard, Paket, HPS) otomatis memfilter berdasarkan OPD terpilih. Kosongkan pilihan untuk melihat semua OPD.
